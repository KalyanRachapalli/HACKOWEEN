# Claude Development Notes & Guidelines

## Execution Commands
- Run Pipeline: `python src/main.py`
- Validate Output: `python src/06_validator.py`
- Run Dashboard: `streamlit run app.py`
- Benchmark Accuracy: `python scripts/check_accuracy.py`

## Requirements
- Python 3.10+
- Pandas, DuckDB, RapidOCR-ONNX, Pydantic, Streamlit, PyPDF
